# Quiz Webapp Context

Interactive quiz application providing presentations, assessments, and immediate feedback.

## Language

**Session**:
A single interactive run through a quiz from start to results.
_Avoid_: Game, playthrough, run

**Question**:
A single challenge in a quiz with text, optional media, options, a correct choice index, and an explanation.
_Avoid_: Slide, item, card

**Option**:
One selectable answer choice in a question.
_Avoid_: Button, answer, choice

**Feedback**:
Sensory response (audio tones and celebratory visual particles) triggered by user performance during a session.
_Avoid_: Effects, sounds, confetti

**Performance**:
The calculated evaluation band derived from score and total questions at session conclusion.
_Avoid_: Grade, tier, result
